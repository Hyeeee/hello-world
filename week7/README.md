# 붕어빵 장인 🐟 Bungeoppang Master — One Button Game

100초 동안 포장마차에서 붕어빵을 구워 손님에게 파는 원버튼 게임.
**SPACE / 마우스 클릭 / 화면 터치** 하나로 모든 걸 조작해요.
- M 키 = 소리 끄기/켜기
- 언어: 시작 화면 오른쪽 위 **한국어 | EN** 버튼, L 키, 또는 주소 뒤에 `?lang=en`

## 게임 방법

| 단계 | 조작 | 잘하는 법 |
|---|---|---|
| 1. 반죽 붓기 | **꾹 누르고 있다가 떼기** | 오른쪽 게이지의 진한 초록 구간에서 떼기. 너무 오래 누르면 넘쳐요 |
| 2. 팥 짜기 | **꾹 누르고 있다가 떼기** | 누르는 동안 짤주머니가 머리 → 꼬리로 움직이며 팥을 쭉 짜요. "여기까지!" 깃발에서 떼기. 꼬리까지 넘어가면 넘침 |
| 3. 뒤집기 | 한 번 누르기 | 노릇해져서 게이지가 초록 칸에 왔을 때 (늦으면 탐) |
| 4. 꺼내기 | 한 번 누르기 | 뒤집은 면도 노릇해졌을 때 |
| 5. 포장·전달 | **자동** | 집게로 꺼내서 봉투에 쏙 → 손님이 받아 가요 |

단계마다 0~100점 (PERFECT / GREAT / GOOD / OK / MISS), 한 마리 최대 400점.
손님이 늘수록 조금씩 빨리 익고, 팥도 빨리 짜져요.

## 파일 구조

```
index.html   ← 라이브러리(p5.js, p5.collide2D)와 JS 파일들을 불러오는 페이지
style.css    ← 캔버스를 화면에 꽉 차게, 모바일 스크롤 막기
sound.js     ← 배경음악 + 모든 효과음 (Web Audio로 직접 합성, 오디오 파일 없음)
i18n.js      ← 한국어 / 영어 글자 전부
art.js       ← 붕어빵, 무쇠 틀, 짤주머니, 주전자, 봉투, 손, 배경 그림
classes.js   ← Bungeoppang, Customer, Steam, Sparkle, Popup 클래스
sketch.js    ← setup()/draw(), 게임 흐름(상태 머신), 입력 처리, UI
```

## 코드가 어떻게 돌아가는지

### 1. 큰 그림: "상태 머신"
게임은 항상 **지금 어느 단계(phase)인지** 하나의 변수로 기억해요.

```
title → pour → bean → cover → cookA → flip → cookB → lift → bagging → handover → (다음 손님) pour …
         ↑누름   ↑누름          ↑누름          ↑누름    └──────── 자동 ────────┘
```

- `phase` : 현재 단계 이름 (문자열)
- `phaseT` : 그 단계가 시작된 뒤 몇 초 지났는지
- `setPhase('cookA')` 를 부르면 단계가 바뀌고 `phaseT` 가 0으로 리셋돼요.

`update(dt)` 안의 `switch (phase)` 가 단계마다 할 일을 정하고,
`press()` / `release()` 가 **"지금 버튼을 누르면/떼면 무슨 일이 일어나는지"** 를 정해요.
버튼은 하나인데 단계마다 다른 동작이 되는 원리예요.

### 2. 원버튼 입력 — "누를 때"와 "뗄 때"
```js
function keyPressed()   { if (key === ' ') press(false); }
function mousePressed() { press(true); }
function touchStarted() { press(true); return false; }
```
키보드·마우스·터치를 전부 `press()` / `release()` 로 모아요.
`held` 변수로 "이미 눌려 있음"을 기억해서, 스페이스바를 꾹 누를 때 키 반복으로 여러 번 눌리는 걸 막아요.

**꾹 누르는(홀드) 조작이 2개** 있어요:
- 반죽: 누르는 동안 `fish.fill` 이 늘어남 → 떼면 `finishPour()` 에서 점수
- 팥: 누르는 동안 `fish.beanEnd` 가 줄어듦(머리→꼬리로 이동) → 떼면 `finishBean()` 에서 점수

### 3. 팥 짜기 로직 (새로 바뀐 부분)
```js
fish.beanStart = 108;   // 머리 쪽 시작점 (붕어빵 안의 x좌표)
fish.beanEnd  -= dt * fish.beanSpeed;   // 누르는 동안 꼬리 쪽으로 이동
```
- 화면에는 `drawBeanRibbon(beanStart, beanEnd)` 가 두 점 사이에 굵은 팥 줄을 그려요. 그래서 짤수록 줄이 길어져요.
- 짤주머니는 항상 `beanEnd` 위치(깍지 끝)에 그려져서 머리에서 꼬리로 따라가요.
- 점수: 뗀 위치가 깃발(`BEAN_TARGET = -80`)에 가까울수록 100점.
- **p5.collide2D** `collidePointEllipse()` 로 깍지 끝이 몸통(타원) 밖으로 나갔는지 매 프레임 확인 → 나가면 "꼬리 밖으로 넘쳤어요" (최대 15점).

### 4. 시간 기반 움직임 (`dt`)
`draw()` 맨 처음에 `dt = deltaTime / 1000` (지난 프레임 이후 흐른 초)를 구해요.
`fish.fill += dt * 0.42` 처럼 모든 움직임에 `dt` 를 곱해서, 컴퓨터가 빠르든 느리든 게임 속도가 똑같아요.

### 5. 점수 계산
"목표에서 얼마나 떨어져 있냐"로 계산해요. 예) 익힘 점수:
```js
100 - Math.abs(d - 0.68) / 0.3 * 100   // 0.68(노릇)에 가까울수록 100점
```
익힘은 `noise()` 로 불 세기가 출렁여서 매번 조금씩 다른 속도로 익어요 (외워서 못 하게).

### 6. 자동 포장·전달
버튼 없이 시간(`phaseT`)에 따라 움직여요.
- `lift` : 집게로 붕어빵을 들어 올리고, 봉투가 아래에서 올라옴
- `bagging` : 붕어빵이 떨어지다가 **p5.collide2D** `collideRectRect()` 로 봉투 입구에 닿으면 봉투 안으로 + 바스락 소리
- `handover` : 봉투가 오른쪽으로 → 손님 손이 들어와서 받으면 점수 정산, 짤랑 → 손님이 봉투를 들고 나감 → 다음 손님

### 7. 클래스와 점(.) 표기법 (classes.js)
- `new Bungeoppang(level)` — 붕어빵 한 마리. `fill`(반죽), `beanStart/beanEnd`(팥), `cookA/cookB`(양면 익힘), `scores`(단계별 점수).
  - `fish.cook(dt)` : 굽기
  - `fish.done` : getter라서 함수인데 변수처럼 읽어요. 지금 굽는 면의 익힘을 돌려줘요.
  - `fish.total()` : 점수 합계
- `new Customer(n)` — 손님. 주문은 **번호**(`orderIdx`)로 저장하고, `customer.order` getter가 현재 언어로 바꿔줘요.
- `Steam`, `Sparkle`, `Popup` — 김/연기, 반짝이, "PERFECT!" 글자. 셋 다 `update()` / `draw()` / `dead` 를 갖고 있어서
  배열에 넣고 한꺼번에 업데이트한 다음 `filter` 로 다 끝난 것만 지워요.

### 8. 한국어 / 영어 (i18n.js)
화면 글자는 전부 `TEXT.ko` / `TEXT.en` 에 들어 있고, 코드에서는 `T('키')` 로 꺼내 써요.
```js
T('title')          // '붕어빵 장인' 또는 'Bungeoppang Master'
T('sold')(3)        // '3마리' 또는 '3 sold' (숫자가 들어가는 건 함수)
```
`LANG` 변수 하나만 바꾸면 전체가 바뀌어요. 선택한 언어는 `localStorage` 에 저장돼서 다음에 열어도 유지돼요.

### 9. 실사 느낌 그래픽 (art.js)
p5의 `fill()` 은 단색만 되기 때문에, p5가 쓰는 캔버스(`drawingContext`)에 직접 그려서 **그라데이션·클리핑·그림자**를 써요.
- **붕어빵 모양** `fishPath()` : 베지어 곡선 + `bumps()` (둥근 혹을 이어 붙이는 함수)로 등/배 지느러미, 꼬리 끝은 지그재그 점들로.
- **양각(볼록) 표현** `relief()` : 같은 선을 ① 오른쪽 아래로 어둡게(그림자) ② 왼쪽 위로 밝게(하이라이트) ③ 원래 자리에 본색 — 3번 겹쳐서 튀어나와 보이게. 비늘, 아가미, 꽃 모양 눈, 입, 지느러미 결, 꼬리 결에 전부 써요.
- **통통한 비늘** `puff()` : 혹마다 밝은 원형 그라데이션 + 꼬리 쪽에 그림자.
- **익는 색** `crustColor(d)` : 익힘 0~1.2를 생반죽색 → 노릇 → 갈색 → 탄색으로.
- **팥** `drawBeanRibbon()` : 굵은 선 + `hash()` 로 정한 알갱이(매 프레임 같은 위치라 안 흔들림) + 윗면 반사광.
- **배경** : 천막, 도시 불빛, 작업대, 가격표를 `createGraphics` 에 한 번만 그려두고 이미지처럼 붙여요 (빠름).
- **화면 크기** : 게임은 항상 960×640 으로 그리고 `scale(sc)` 로 창 크기에 맞춰 늘려요.

### 10. 소리 (sound.js) — 파일 없이 전부 합성
`Sound` 객체 하나에 모든 소리가 있어요. 브라우저는 처음 누르기 전엔 소리를 막기 때문에 첫 `press()` 에서 `Sound.init()`.
- 기본 재료: `_tone()` (오실레이터 = 삐/띵) 과 `_burst()` (필터 건 노이즈 = 칙/착/바스락)
- **배경음악**: 84 BPM 로파이 재즈 4마디 루프 (코드, 베이스, 드럼, 오르골 멜로디, LP 지직)
- **반죽**: 꿀렁꿀렁 + 보글보글 / **팥**: 낮고 끈적한 '쮸욱' + 끊길 때 '뽁'
- **지글지글**: 익을수록 커지고 '탁탁' 기름 튀는 소리 / **철컹**: 금속 배음(1, 2.32, 4.25…배)
- 집게 '쏙', 종이봉투 바스락, 계산 '짤랑', 탈 때 경고음, 마지막 10초 째깍, 종료 징글
