# 붕어빵 장인 🐟 Bungeoppang Master — 3D One Button Game

포장마차에서 100초 동안 붕어빵을 구워 손님에게 파는 원버튼 게임 (Three.js 3D 버전).
**SPACE / 클릭 / 터치** 하나로 조작. M = 소리, L = 언어.
언어는 화면 오른쪽 위 **한국어 | EN** 버튼으로 시작 화면에서도, 플레이 중에도 바꿀 수 있어요.

## 게임 방법

| 단계 | 조작 | 잘하는 법 |
|---|---|---|
| 1. 반죽 붓기 | **꾹 누르고 있다가 떼기** | 게이지 진한 초록 구간에서 떼기 |
| 2. 팥 짜기 | **꾹 누르고 있다가 떼기** | 짤주머니가 머리 → 꼬리로 이동. "여기까지!" 깃발에서 떼기 |
| 3. 뒤집기 | 한 번 누르기 | 노릇해서 게이지가 초록 칸일 때 |
| 4. 꺼내기 | 한 번 누르기 | 반대쪽도 노릇할 때 |
| 5. 포장·전달 | 자동 | 집게로 봉투에 → 손님이 받아감 |

## 파일 구조

```
index.html      ← 3D 캔버스 + HTML UI + Three.js 불러오기(importmap)
style.css       ← 위에 겹치는 UI (점수, 단계, 게이지, 말풍선, 시작/종료 화면)
sound.js        ← 배경음악 + 효과음 (Web Audio로 합성, 오디오 파일 없음)
i18n.js         ← 한국어 / 영어 글자
js/art2d.js     ← 붕어빵 외곽선, 비늘·눈·지느러미 결, 반죽 그림 (2D)
js/textures.js  ← 코드로 그린 텍스처: 원목, 무쇠 질감, 붕어빵 표면/요철, 두께 지도, 종이봉투
js/models.js    ← 3D 물체: 조리대, 무쇠 틀, 붕어빵, 반죽, 팥, 주전자, 짤주머니, 집게, 봉투, 손
js/main.js      ← 장면·카메라·조명, 게임 흐름, 입력, UI 업데이트
```

> 모듈(`type="module"`)을 쓰기 때문에 파일을 더블클릭해서 열면 안 되고,
> **Live Server** 나 **GitHub Pages** 처럼 웹 서버로 열어야 해요.

## 코드가 어떻게 돌아가는지

### 1. p5.js 버전과 뭐가 달라졌나
p5 2D 버전은 그림을 "손으로 그려서" 입체처럼 **흉내** 냈어요.
이번엔 **Three.js** 로 진짜 3D 물체를 만들고, 조명이 표면에 닿는 걸 컴퓨터가 계산해요.
그래서 그림자, 금속 반사, 볼록한 비늘의 명암이 저절로 생겨요.

Three.js의 기본 구성 4가지:
- **Renderer** (`WebGLRenderer`): 3D를 화면 캔버스에 그려주는 엔진
- **Scene**: 물체·조명이 들어가는 공간
- **Camera** (`PerspectiveCamera`): 위에서 비스듬히 내려다보는 눈
- **Mesh** = 모양(Geometry) + 재질(Material). 예: 붕어빵 = 격자 판 모양 + 빵 재질

### 2. 실사 느낌을 만드는 설정 (main.js 위쪽)
- `shadowMap` + `PCFSoftShadowMap` : 부드러운 그림자
- `ACESFilmicToneMapping` : 영화처럼 자연스러운 밝기/색
- `RoomEnvironment` : 가상의 방을 비춰서 금속(주전자, 집게)에 반사가 생김
- `MeshPhysicalMaterial` : 거칠기(roughness), 코팅(clearcoat), 빵 표면 광택(sheen) 같은 실제 재질 속성
- 조명: 하늘빛(Hemisphere) + 왼쪽 위 주 조명(Directional) + 굽는 동안 주황빛(Point)

### 3. 붕어빵 3D 만들기 (가장 중요!)
"배는 통통, 끝으로 갈수록 날렵하게"를 이렇게 만들었어요.

1. **외곽선** `fishPath()` (art2d.js) — 베지어 곡선으로 뾰족한 코, 아가미 뒤가 제일 넓은 몸통, 가는 꼬리자루, 넓은 꼬리.
   같은 함수가 2D 캔버스(텍스처)와 3D(틀 구멍)에 둘 다 쓰여요. `adapter()` 가 2D 명령을 Three.js `Shape` 명령으로 바꿔줘요.
2. **두께 지도** `fishThickness()` (textures.js) — 붕어빵 실루엣을 흰색으로 칠하고 **크게 블러**해요.
   넓은 몸통 가운데는 하얗게 남고, 좁은 꼬리·지느러미·테두리는 회색이 돼요. → 그 값을 높이로!
3. **격자 판 들어올리기** `makeFish()` (models.js) — 220×220 칸 판의 점마다 두께 지도 값만큼 위로 올려요.
   `pow(t, 0.55)` 로 가운데는 둥글게, 가장자리는 빠르게 얇아지게. 붕어빵 바깥은 텍스처가 투명해서 `alphaTest` 로 잘려나가요.
4. **비늘·눈·지느러미 결** — `bumpMap`(흑백 높이 그림, 밝을수록 볼록)으로 표현. 조명이 이걸 보고 명암을 넣어요.
5. **익는 색** — `crustColor(d)` 가 익힘 값을 색으로 바꾸고, 매 프레임 재질 색(`mat.color`)에 넣어요.

### 4. 반죽과 팥
- **반죽**: 2D 캔버스에 반죽 퍼지는 모양을 매 프레임 그려서(`drawBatter`) 3D 판의 텍스처로 씀 → 차오를수록 판이 위로 올라감.
- **팥**: `TubeGeometry` — 머리(`beanStart`)부터 지금 깍지 위치(`beanEnd`)까지 곡선을 따라 튜브를 만들어요.
  누르는 동안 `beanEnd` 가 꼬리 쪽으로 이동하니까, 매 프레임 튜브를 다시 만들면 "쭉 짜지는" 모습이 돼요. 양 끝은 구로 둥글게.
- 깍지가 몸통 타원 밖으로 나가면 (`((x-5)/110)² > 1`) 꼬리로 넘친 것 → 감점.

### 5. 게임 흐름 = 상태 머신
`S.phase` 하나가 지금 단계를 기억해요.
```
title → pour → bean → cover → cookA → flip → cookB → lift → bagging → handover → 다음 손님
         ↑누름   ↑누름          ↑누름          ↑누름    └──── 자동 ────┘
```
- `update(dt)` : 단계별 로직 (반죽 양 늘리기, 굽기, 시간 등)
- `syncScene(dt)` : 지금 상태에 맞춰 3D 물체 위치·보이기/숨기기·색 맞추기
- `updateHUD()` : HTML UI 글자/게이지 업데이트
- `press()` / `release()` : 원버튼 입력. 단계마다 다르게 반응

### 6. 뒤집기 / 포장 애니메이션
- 뒤집기: 틀과 붕어빵을 `moldPivot` 그룹에 묶어서 그룹째 x축으로 한 바퀴(`rotation.x = 2π × 진행도`) + 살짝 들어올림.
- 꺼내기: `scene.attach(fishMesh)` 로 붕어빵을 틀에서 떼어내고, 집게 위치로 이동하며 세워요(`rotation.x = π/2`).
- 봉투: 떨어지는 속도(`fallV`)에 중력을 더하다가 봉투 높이에 닿으면 멈추고 바스락.
- 전달: 봉투가 오른쪽으로, 손님 손이 들어와 받고 같이 나가요.

### 7. UI는 HTML
점수, 단계, 게이지, 말풍선, 점수 팝업은 3D가 아니라 HTML이라 글씨가 선명해요.
점수 팝업과 팥 깃발은 3D 위치를 `vector.project(camera)` 로 화면 좌표로 바꿔서 그 자리에 띄워요.

### 8. 한국어 / 영어
글자는 전부 `i18n.js` 에 있고 `T('키')` 로 꺼내요. 오른쪽 위 버튼이나 L 키로 바꾸면 `applyTexts()` 가 화면 글자를 전부 다시 써요.
버튼을 누를 땐 게임 입력(press)이 안 되도록 `#lang` 안의 클릭은 무시해요.

### 9. 소리 (sound.js)
p5 버전과 같아요. 반죽 꿀렁, 팥 쮸욱, 지글지글, 철컹, 바스락, 짤랑, 로파이 배경음악까지 전부 코드로 합성.
